# Checklist visual

Marcá cada ítem como pasa, falla o no aplica. No reemplaces una falla con una explicación.

## Sistema

- [ ] Usa `#14110e` / `#1e1a14`, brass `#c9a36a`, cream `#f3e6cf`, sea `#2f5658`, moss `#7ea37c`, rust `#c45c4a` y mist `#b7a78e` con roles consistentes.
- [ ] Títulos serif y UI sans humanista conservan jerarquía.
- [ ] Las superficies parecen madera, papel o metal; no vidrio frío.
- [ ] No hay neón, violeta SaaS, cards blancas dominantes ni pills excesivas.
- [ ] El foco de teclado es visible.
- [ ] Texto normal alcanza 4.5:1 y texto grande o límites de controles 3:1.

## Iconos

- [ ] Cada edificio se reconoce a 24 px sin etiqueta.
- [ ] Las variantes 24/32/48 comparten centro óptico y perspectiva.
- [ ] Edificios de la misma cadena se distinguen por silueta y rasgo funcional.
- [ ] Los SVG no contienen `<image>`, raster embebido, fuentes ni URLs externas.
- [ ] La familia usa arte original; no hay contornos, detalles o poses calcados.

## Grilla

- [ ] El 10×10 tiene diez filas y diez columnas.
- [ ] Las casas leen como huellas 3×3.
- [ ] Calle, jardín, agua, granja, industria y vacío se distinguen por más que color.
- [ ] Los edificios importantes aparecen dentro de la grilla.
- [ ] Cobertura de mercado no tapa huellas ni iconos.
- [ ] `zzz` está unido a la fábrica correspondiente y no parpadea.
- [ ] Una persona puede responder cuatro de cinco preguntas de la prueba de tres segundos.

## Misión y copy

- [ ] La misión actual domina y el futuro no revela spoilers.
- [ ] “Dónde mirar en el juego” usa texto o diagrama original, no screenshot.
- [ ] Hay una sola acción principal.
- [ ] El español usa voseo natural y frases cortas.
- [ ] `en`, `it` y `de` preservan intención, variables y longitud razonable.
- [ ] No hay `vosotros`, “estimado usuario” ni lenguaje de KPI.

## Pulso y tablero

- [ ] Monedas suben, bajan y desconocidas tienen forma, texto y color.
- [ ] Casas vacías, amarillas y ocupadas no dependen solo del color.
- [ ] Las cadenas son relaciones visuales simples, no tablas de producción.
- [ ] Presencia nunca aparece como conteo o porcentaje inventado.
- [ ] Tooltips indican fuente, momento y límite cuando esos datos existen.
- [ ] Los valores ausentes se muestran como desconocidos, no como cero.

## Segundo monitor y motion

- [ ] La lectura primaria tarda menos de tres segundos.
- [ ] Desktop mantiene densidad compacta y móvil no desborda horizontalmente.
- [ ] Objetivos táctiles importantes alcanzan 40 px.
- [ ] Motion dura 110–260 ms y se siente corto y pesado.
- [ ] `prefers-reduced-motion` elimina animación no esencial.
- [ ] No hay bounce, overshoot, confetti ni pulso infinito.

## Propiedad intelectual

- [ ] No hay logos de Ubisoft o Anno.
- [ ] No hay screenshots, renders, retratos o UI del juego embebidos.
- [ ] No hay hotlinks a Fandom, Ubisoft, Nexus u otros hosts de assets.
- [ ] No hay packs comunitarios reutilizados tal cual.
- [ ] Las fuentes aparecen como referencias de estudio, no como archivos del producto.
- [ ] El footer dice “Proyecto fan no oficial; no afiliado a Ubisoft.”

## Resultado

Aprobá solo si no queda ninguna falla obligatoria. Documentá excepciones de “no aplica” con una frase. Si aparece arte oficial o un conteo inventado, tratá el hallazgo como bloqueante.
