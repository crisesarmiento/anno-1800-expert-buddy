# Registro acotado de fuentes

Elegí la página más específica para la pregunta. Leé y citá; no descargues sus imágenes.

## Fuente oficial de tono

- Anno Union: https://www.anno-union.com/

Usá artículos y DevBlogs para estudiar tono editorial, proceso y vocabulario general. No extraigas key art, UI, renders, retratos ni logos.

## Juego

Observá localmente, cuando el usuario tenga acceso legítimo:

- diario y jerarquía de misión;
- Estadísticas → Economía;
- barra de necesidades;
- sellos o categorías de misión;
- silueta general de edificios.

No pidas al usuario que suba capturas oficiales al repositorio. Si comparte una imagen para análisis, tratala como referencia temporal y no la empaquetes.

## Registro de decisión

Cuando una fuente influya materialmente en un diseño, dejá una nota breve en la documentación de trabajo con URL, aspecto observado y transformación original. No agregues archivos derivados de la fuente.
